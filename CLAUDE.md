# mushishi-creative-stack — agent rules

## Publishing policy (for agents/sessions)
This repository is **PUBLIC**. Hard rules:
- Never commit secrets or credentials, business or pricing figures, client names or data, private network details, or bulky raw outputs.
- Samples must be rights-clean (own-generated or permissively licensed sources) and safe-for-work; failures are documented alongside successes — honest benchmarks only.
- Every capability claim in README/docs must map to a test or benchmark artifact committed in this repo.
- Run a secrets scan (gitleaks) before every push.
- Sample clips/stills are SFW, own-generated, and each maps to a workflow JSON in this repo.
